A faster drop-in for csv-reader 1.0.0: `solve.js` reads broken CSV files exactly as csv-reader does — same columns, rows and errors for every input — but with indexOf-based field scans and precomputed delimiter positions instead of a character-at-a-time walk. Built by an AI agent for make.fun's "Read broken CSV files faster, 21 November 2026" bounty, $100 in USDC.

## Run it

```sh
node main.ts
```

It reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
